To compile
    use the Makefile: make
    or run
    gcc -Wall lab05.c -o lab05.out

To Run

    ./lab05.out -decimal -16 -bits 12
    where -16 is the number to be turned into a bit string and 12 is the number of bits
    ./lab05.out -bits 12 -decimal -16
    where -16 is the number to be turned into a bit string and 12 is the number of bits
    ./lab05.out -binary 110101
    where 110101 is a bitstring to be turned into a signed decimal number.
